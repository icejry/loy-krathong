# ลอยกระทงริมสายน้ำ · Living River

เว็บไซต์ลอยกระทงแบบ Interactive ที่เขียนขึ้นสำหรับโปรเจกต์นี้โดยเฉพาะ ใช้งานแบบ Static Website **ไม่ต้องติดตั้ง Node.js หรือไลบรารี** มีไฟล์เสียงบรรเลงต้นฉบับ โหมดตกแต่งกระทง บันทึกคำอธิษฐาน และหน้าประวัติ

## เริ่มใช้งาน

**ง่ายที่สุด:** แตก ZIP แล้วเปิด `open-directly.html` โดยให้โฟลเดอร์ `assets/`, `css/`, `js/` อยู่ร่วมกันตามเดิม (อินเทอร์เน็ตช่วยโหลด Google Fonts แต่มีฟอนต์สำรอง)

**สำหรับพัฒนา/ขึ้นเว็บจริง:** รันเว็บผ่าน HTTP server จากโฟลเดอร์นี้

```bash
python3 -m http.server 8000
```

เปิด `http://localhost:8000` บนเบราว์เซอร์ หรือดับเบิลคลิก `start-mac.command` บน macOS / `start-windows.bat` บน Windows ที่มี Python

**Deploy:** อัปโหลดไฟล์ทั้งหมดขึ้น Netlify, Vercel (Static Site), Cloudflare Pages หรือ GitHub Pages ได้เลย โดยใช้ `index.html` เป็นหน้าเริ่มต้น (ไม่ต้องมี build step)

## ฟีเจอร์

- ภาพแม่น้ำกลางคืนจาก Canvas 2D: พระจันทร์ ภูเขา วัด แสงสะท้อน ระลอกคลื่น และประกายไฟ
- กระทง SVG วาดขึ้นใหม่ ปรับฐาน **6** แบบ × ดอกไม้ **8** × สีขอบ **6** × เทียน **5** × ประดับ **6** × ความแน่นดอกไม้ **3** = **25,920** รูปแบบ
- เมื่อปล่อยกระทง จะเคลื่อนจากด้านหน้าเข้าแม่น้ำ มีแสงและระลอกน้ำ แล้วลอยค้างอยู่ในฉากต่อ
- คลิก/แตะกระทงเพื่ออ่านคำอธิษฐาน; กระทงของตัวเองมีป้ายระบุ
- กระทงตัวอย่าง 8 ใบ มีคำอธิษฐานตัวอย่าง ไม่ได้แอบอ้างว่าเป็นผู้ใช้จริง
- บันทึกกระทงของตนเองใน `localStorage` สูงสุด 24 ใบ โดยไม่ต้องมีบัญชี (ถ้าบราวเซอร์อนุญาต)
- ดนตรีประกอบ MP3 ความยาว 60 วินาทีที่แต่งและสังเคราะห์ขึ้นใหม่สำหรับโปรเจกต์นี้ พร้อมเสียงชิมเมอร์เมื่อเลือก/ปล่อยกระทง
- หน้าเรื่องราวประวัติ มีคำอธิบายความเชื่อและข้อจำกัดหลักฐานนางนพมาศ พร้อมลิงก์ที่มา
- ดีไซน์รองรับ desktop / tablet / mobile, `prefers-reduced-motion`, คีย์บอร์ด และการอ่านคำอธิษฐานอย่างชัดเจน

## ทำไมเพลงไม่เล่นทันทีตอนเปิดหน้า?

Chrome, Safari, Firefox และเบราว์เซอร์มือถือจำนวนมากไม่อนุญาต autoplay แบบมีเสียงก่อนผู้ใช้โต้ตอบ เพลงจะเล่นเมื่อแตะ/คลิก/กดปุ่มครั้งแรก **ไม่มีเมนูตั้งค่าเสียง** เพื่อให้ขั้นตอนเรียบง่าย; ไม่ควรหลอกผู้ใช้ว่า autoplay มีเสียงทำได้ในทุกระบบโดยไม่ต้องสัมผัส

ใช้เพลงต้นฉบับที่ไม่ดัดแปลงเพลง “รำวงลอยกระทง” หรืออัดเสียงเพลงที่มีลิขสิทธิ์ ตัวเสียงอยู่ที่ `assets/moonriver-original.mp3` แก้เพลงได้โดยแทนไฟล์ดังกล่าว

## เปิดระบบเห็นกระทงของผู้ใช้อื่นจริง

ค่าเริ่มต้น **Demo/Local Mode** มีเพียงกระทงตัวอย่างและกระทงของอุปกรณ์นี้ เพราะโปรเจกต์ยังไม่มีฐานข้อมูลหรือคีย์ส่วนตัวของผู้ใช้

1. สร้างโปรเจกต์ Supabase ของตัวเอง
2. เปิด SQL Editor และรัน `backend/supabase.sql` เพื่อตั้งตารางและ Row Level Security
3. เปิด `js/config.js` กรอก `supabaseUrl` และ `supabaseAnonKey` ซึ่งเป็น **publishable/anon key เท่านั้น** ห้ามใส่ service_role หรือ secret key
4. Deploy เว็บไซต์ จากนั้นระบบจะดึงกระทงสถานะ `approved` มาแสดงและอัปเดตทุก **20 วินาที** (polling แบบเกือบเรียลไทม์ ไม่ใช่ WebSocket instant)
5. คำอธิษฐานใหม่จะถูกส่งด้วยสถานะ `pending` แล้วแสดงในเครื่องผู้ส่งทันที **ยังไม่แสดงแก่ทุกคน** จนผู้ดูแลอนุมัติใน Supabase Dashboard (`status = approved`)

**ก่อนเปิดรับผู้ใช้สาธารณะ:** โปรดเพิ่ม rate limiting และ CAPTCHA หรือ Edge Function, ระบบรายงานข้อความ, นโยบายจัดเก็บ/ลบข้อมูล, และการดูแล moderation; SQL ที่ให้มาช่วยจำกัดการเผยแพร่ แต่ไม่ได้ป้องกันการส่งคำขอจำนวนมาก

## ไฟล์สำคัญ

- `index.html` — โครงสร้างเว็บไซต์ (ES modules, เหมาะกับการ deploy)
- `open-directly.html` — ทางเลือกเปิดหน้าเว็บจากเครื่องโดยไม่ต้องเปิดเซิร์ฟเวอร์ (สร้างจาก source เดียวกัน)
- `css/styles.css` — สไตล์/Responsive
- `js/krathong.js` — วาดและจัดชั้นกระทง SVG
- `js/river.js` — Canvas และแอนิเมชันแม่น้ำ
- `js/app.js` — ตัวเลือกและปฏิสัมพันธ์ UI
- `js/audio.js` — เสียงเพลงและเสียงตอบสนอง
- `js/data.js` — ตัวเลือกสี รูปทรงและข้อมูลกระทงตัวอย่าง
- `js/storage.js` — localStorage และ Supabase REST
- `assets/moonriver-original.mp3` — เพลงบรรเลงต้นฉบับ 60 วินาที
- `backend/supabase.sql` — ฐานข้อมูลและ RLS สำหรับโหมดออนไลน์
- `tests/make_music.py` — สคริปต์สร้างดนตรีต้นฉบับ
- `tests/build_standalone.py` — สร้าง `open-directly.html` จากซอร์สใหม่หลังแก้โค้ด

## ขอบเขตการทดสอบ

ตรวจ Syntax JavaScript ด้วย `node --check`, ตรวจ SVG ที่สร้างผ่าน XML parser, ตรวจไฟล์เพลงด้วย `ffprobe`, ทดสอบ HTTP server และใช้ Playwright/Chromium ทดสอบการแต่งกระทง การปล่อยกระทง การอ่านคำอธิษฐาน หน้าประวัติ และไม่มี horizontal overflow ที่หน้าจอ 1440px, 768px, 390px ผ่านแล้ว (`tests/qa_browser.py` โดยนำโค้ดเดิมมา inline ในเบราว์เซอร์ทดสอบ เนื่องจากเครื่องทดสอบห้ามนำทางไปยัง URL ภายใน) การทดสอบนี้ไม่ได้ทดสอบ Safari, Firefox หรืออุปกรณ์จริง จึงควร QA เพิ่มก่อนเผยแพร่สาธารณะ


## อัปเดตเวอร์ชันใหม่

- แตะท้องฟ้าเพื่อปล่อยโคมลอย แตะผิวน้ำให้เกิดระลอก มีโคมลอยและดาวตกเคลื่อนไหวเอง
- ปุ่มสุ่มกระทง และคำอธิษฐานแนะนำให้แตะเลือก
- บันทึกเป็นการ์ดภาพ (PNG) หรือแชร์ผ่านเมนูแชร์ของมือถือ
- ข้อความนับถอยหลังถึงวันลอยกระทง (แก้วันที่ได้ที่ `FESTIVAL_DATES` ใน `js/extras.js`)
- ปุ่มเปิด/ปิดเสียงเพลง (จำค่าไว้ในเครื่อง)
- ติดตั้งเป็นแอปบนมือถือได้ (PWA) และเปิดซ้ำแบบออฟไลน์ได้ (`manifest.webmanifest`, `sw.js`)
- ปรับ responsive: มือถือจอเล็ก, แนวนอน, แท็บเล็ต, จอใหญ่พิเศษ, รองรับรอยบากจอ และปุ่มขนาดเหมาะกับการสัมผัส
- หลังแก้โค้ด ให้รัน `python3 tests/build_standalone.py` เพื่อสร้าง `open-directly.html` ใหม่
